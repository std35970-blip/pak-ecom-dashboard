# 🚀 Getting Started with PakBiz Dashboard

## How to Open the Dashboard

### Method 1: Double-Click (Easiest!)
1. Navigate to the folder where you downloaded PakBiz Dashboard
2. Find the file called `index.html`
3. **Double-click on `index.html`**
4. Your default web browser will open with the dashboard

### Method 2: Right-Click and Open With
1. Find `index.html` in the folder
2. **Right-click** on it
3. Select **"Open with"**
4. Choose your preferred browser:
   - Google Chrome
   - Mozilla Firefox
   - Microsoft Edge
   - Safari (Mac)

### Method 3: Drag and Drop
1. Open your web browser (Chrome, Firefox, Edge, Safari)
2. Find the `index.html` file
3. **Drag and drop** the file into the browser window

### Method 4: From Command Line/Terminal

**On Windows:**
```bash
start index.html
```

**On Mac:**
```bash
open index.html
```

**On Linux:**
```bash
xdg-open index.html
```

## First Steps After Opening

### 1. Explore the Sample Data
The dashboard comes with realistic sample data so you can:
- See how orders are displayed
- Understand the analytics
- Test all features without risk

### 2. Customize Your Settings
Click on **⚙️ Settings** in the sidebar and add:
- Your business name
- Your name
- Your phone number
- Your city
- Default courier preference
- Default payment method

### 3. Start Adding Your Orders
Click on **📦 Orders** then:
- Click the **"+ Add Order"** button
- Fill in customer and order details
- Save your order
- It will appear in the orders table immediately

### 4. Use the Profit Calculator
Click on **💰 Profit Calculator** to:
- Enter your product cost
- Enter selling price
- Add shipping and other costs
- See instant profit calculations

## Common Questions

### Q: Do I need internet to use this?
**A:** No! The dashboard works completely offline once opened.

### Q: Where is my data stored?
**A:** All data is stored locally in your browser's localStorage. It stays on your computer only.

### Q: Can I delete the sample data?
**A:** Yes! Go to Orders page and delete any order by clicking the "Delete" button.

### Q: Can I access this on my phone?
**A:** Yes! Open the `index.html` file in your mobile browser. The dashboard is fully responsive.

### Q: How do I backup my data?
**A:** Your data is in your browser's localStorage. To backup:
1. Open browser developer tools (F12)
2. Go to Application/Storage tab
3. Find localStorage
4. Copy the data
5. Save it to a text file

### Q: Can I share this with my team?
**A:** Yes! Just send them the entire folder. Each person will have their own local data.

### Q: Is it safe?
**A:** Yes! No data leaves your computer. Everything is stored locally in your browser.

## Troubleshooting

### Problem: Nothing happens when I double-click
**Solution:** 
- Make sure you're clicking `index.html` (not a folder)
- Try right-click → Open with → Choose your browser
- Make sure you have a modern web browser installed

### Problem: Page looks broken or charts don't show
**Solution:**
- Make sure you're connected to the internet for the first load (for Google Fonts and Chart.js)
- Try a different browser (Chrome or Firefox recommended)
- Clear your browser cache and reload

### Problem: My data disappeared
**Solution:**
- Data is stored per browser. If you switched browsers, your data is still in the original browser
- Don't use "incognito/private" mode as it doesn't save data permanently

### Problem: Can't add orders
**Solution:**
- Make sure all required fields are filled (customer name, phone, product, price)
- Try refreshing the page
- Check browser console for errors (F12 → Console tab)
